Where They Differ

Same algorithm, two accents — the differences aren't bugs, they're each language's idiom showing through.

Size of a folder
Ruby child.size the folder is an object
Perl -s $full a built-in operator
Locked folder
Ruby rescue => e raise and catch
Perl opendir or return 0 check the return
Divider line
Ruby ━ × 45
Perl ━ × 30
we never bothered to match them
Everything else matches — same walk, same formatting, same bars.
03

Key Learnings

Locked folders are the rule, not the edge case — macOS hides plenty. Ruby raises and you rescue; Perl returns 0 and you check. Both survive, they just say "skip it" differently.

Re-walking is the O(n²) trap — walking each subtree once per child was fine on shallow dirs, brutal on deep ones. One pass per directory fixed it.

Bytes are noise — the divide-by-1024 B/K/M/G/T/P ladder is what turns a wall of digits into "2.5G".

The charts matched by accident — same ▇/░ formula in both, so parity wasn't chased, it just fell out.
